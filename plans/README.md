7. The CLI could not reach proxied nodes; 011 adds `BIRDSONG_URL`.
8. The ether already works behind prefix stripping (`pathname === '/listen'`); only `ETHER_URL` changes.

## Design decisions that are settled (do not re-litigate in plans)

- One Docker node per Linux laptop, real speaker and mic via the host PipeWire-Pulse socket; phones join as full nodes through a static HTTPS PWA.
- TypeScript everywhere, one pure `core` package for Node and browser, no build step for Node (native type stripping).
- Shared-passphrase AES-GCM, key in the QR fragment. Static compression only, **no LLM** (Accenture fit is pitch-only, a known weakness).
- Telemetry to the dashboard is an observer channel only; message data travels only through sound.
- The simulated air (ether) is for development, CI and the fallback demo.

## Changes made while writing these plans (vs. the approved design)

These came out of stress-testing the design; they are reflected in the plans:

1. **Reed–Solomon added inside each frame** (8 parity bytes, corrects 4 bad
   bytes). The design had CRC only, so one wrong symbol out of ~60 lost the
   whole frame; in a real room that would be most frames. Frame on air is now 32 bytes, not 24.
2. **Vandermonde fountain instead of PRNG coefficients.** Coefficient α^(seed·i)
   makes *any* k distinct droplets decodable (no "k+1 with high probability").
   Seeds are one byte, so a message has 255 distinct droplets.
3. **One shared sync sweep for all species.** The design gave each species its
   own preamble, which would have made the receiver search 4 templates. Now the
   species differ only in decorative intro notes and timbre; the receiver uses one sync template.
4. **Energy-based carrier sense.** A sync is detected only ~0.4 s into a
   frame, too late for listen-before-sing. The modem's `busy()` now also
   reports recent in-band energy.
5. **Relay burst with suppression, then Trickle.** Pure Trickle relays only one
   droplet per interval, so multi-hop delivery of a k-block message would take
   minutes. A node that decodes now sends k droplets at once (skipped if
   neighbours already sang k), then trickles. Tombstones stop expired messages from resurrecting.
6. **Interfaces made concrete:** `AudioPort.start/stop`, `Clock.clearTimeout`,
   `BirdNode.settled()` (so simulations wait for async crypto), sweep of 3
   semitones per chirp, intro/sync/data timeline, sample-rate-agnostic modem (phones run at 44.1 kHz).
7. **npm workspaces instead of pnpm** (pnpm and corepack are not installed on the dev machine).

## Findings considered and rejected

- *Per-recipient public-key encryption*: rejected for the MVP (key exchange UI, airtime for public keys). Shared passphrase per channel instead.
- *Network-coded relaying from a partial rank*: real gain only in large meshes; deferred (noted in plan 005).
- *Running the modem in a Web Worker*: deferred unless plan 008 measures main-thread stalls over 1 s.
- *Real-room acoustic delay in the simulated air*: frames are seconds long, rooms are milliseconds; reverb is tested in plan 003 instead.
- *Real laptop nodes behind port 3100*: they run with host networking on other machines; would need an `--advertise <url>` flag. Deferred.
- *Dashboard "Interactions" panel*: `GET /api/log` and the NDJSON file are enough for now; add a panel if the demo needs it.
- *Dropping `|| true` from the Dockerfile's web/dashboard build*: hides build failures, but unrelated to the port change; not in 011–013.
- *Caddy `map`/placeholder upstreams instead of eight explicit blocks*: shorter but harder for an executor to verify; eight literal blocks chosen.

## Cold-read review — outcome

Two fresh-context reviews were run (plans 001–005 and 006–010); 44 findings,
all applied. The ones that change how executors work:

- **TypeScript is pinned to 5.8** (npm `latest` is TypeScript 7; 5.9+ breaks `Uint8Array` → WebCrypto typings).
- `fft.js` ships its own types (no shim); `unishox2.siara.cc` gets a shim in plan 001, referenced with `/// <reference>` so every package sees it.
- `@birdsong/ether` exports `./src/client.ts`.
- **Shared working tree:** executors judge `typecheck`/`test` output only for
  their own directories, and "done" checks use `git log -1 --name-only` (what
  *they* committed), not `git status` (which shows everyone's work in progress).
- Coast band corrected to 1057–3073 Hz; laptop ids 0–127, phone ids 128–255; hub stamps event times with its own clock.
- Accepted residual risk: the coast/fast symbol templates have the thinnest
  separation (max cross-correlation ≈ 0.55 against a 0.6 limit); plan 003's test reports it.
